# Generative Music
- -------------

Experimentations with 🎵[Tone.js](https://tonejs.github.io/examples/) to create generative music. 

I was really inspired by [Tero Parviainen's essay Javascript Systems Music](https://teropa.info/blog/2016/07/28/javascript-systems-music.html) which is a great introduction both to generative / systems music but also to the Tone.js library. 

I also wanted to experiment a bit with using Glitch as a sandbox. I also want to see if I can use smaller Glitch projects to augment a post on my personal blog.

### ← script.js 🎹
Most everything interesting is in the javascript file.

Using [Tonal.js](https://github.com/danigb/tonal) to get useful scales and chords

Using [Chance.js](https://chancejs.com/) for randomization

### ← README.md ✍️
Description of this project and the motivations behind it.

### ← index.html 📎
Pull in Tachyons (for basic styling) as well as Tone JS and jQuery. Create a wrapper for the page that the javascript is looking for clicks on.
