# glitch
Archived projects from Glitch.com (RIP)

## What is this?

Glitch.com was an old FogCreek Software integrated code IDE / web hosting platform. It had a good run and made the web fun again for a little while. https://en.wikipedia.org/wiki/Glitch,_Inc.  I made a bunch of fun little projects there and this is archive I downloaded when they disappeared. The Internet isn't forever unless we keep it. 

Trying to deploy a few projects to bengarvey.com so you can view them.
